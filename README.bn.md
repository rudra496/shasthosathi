# স্বাস্থ্যসাথী (ShasthoSathi)

> **স্বাস্থ্যকর্মীদের জন্য অফলাইন এআই স্বাস্থ্যসঙ্গী।**
> লাইভ ডেমো: **https://rudra496.github.io/shasthosathi/**

## সমস্যাটা কী?
২০২৩ সালে বাংলাদেশে ইতিহাসের সবচেয়ে ভয়াবহ ডেঙ্গু মহামারি হয়: **৩,২১,১৭৯ জন ভর্তি, ১,৭০৫ জনের মৃত্যু** (স্বাস্থ্য অধিদপ্তর)। প্রতি বছর ডেঙ্গু ফেরে, কিন্তু দেশের প্রথম সারির সেবাদাতা — কমিউনিটি স্বাস্থ্যকর্মীরা — কোনো এআই সহায়তা ছাড়াই কাজ করেন, অনেক সময় ইন্টারনেট ছাড়া এলাকায়। রোগ ধরা পড়ে কয়েক সপ্তাহ দেরিতে।

## আমাদের প্রতিশ্রুতি: কোনো সংখ্যা বানানো নয়
অ্যাপের প্রতিটি সংখ্যার উৎস আছে: ২০২৩-এর মাসিক ডেঙ্গু সিরিজ এসেছে পিয়ার-রিভিউড পেপার থেকে (Hossain et al. 2025, doi:10.1002/hsr2.70852); বছরভিত্তিক সংখ্যা DGHS/IEDCR/WHO; আবহাওয়া Open-Meteo-র সত্যিকারের পর্যবেক্ষণ; ম্যাপ geoBoundaries; জনসংখ্যা BBS আদমশুমারি ২০২২। প্রমাণপত্রে **৪৯টি Crossref-যাচাইকৃত পিয়ার-রিভিউড পেপার** — দেখুন [docs/EVIDENCE.md](docs/EVIDENCE.md)। যা পাইনি, সেটাও আমরা স্বীকার করি (বানাইনি)।

## সৎ স্বীকারোক্তি
- ট্রায়াজ ইঞ্জিন **নিয়মভিত্তিক (WHO 2009)** — জেনারেটিভ এআই দিয়ে রোগ নির্ণয় নয়। প্রতিটি স্ক্রিনে লেখা: *চিকিৎসকের বিকল্প নয়*।
- পূর্বাভাস মডেল **প্রমাণ-অব-কনসেপ্ট** — ১২ মাসের যাচাইকৃত ডেটায় প্রশিক্ষিত; এর দুর্বলতাও অ্যাপেই প্রকাশ করা (মহামারি-বার্নআউট ধরতে পারে না)। এটি **আপেক্ষিক ঝুঁকি সূচি** দেয়, পরম সংখ্যা নয়।
- ওষুধ পাঠ **পরীক্ষামূলক** — ফলাফল যাচাই করতে বলা আছে।
- ফোনে চলা LLM (Gemma/MedGemma), ওয়ার্ড-লেভেল পূর্বাভাস, SMS গেটওয়ে — **ভবিষ্যৎ পরিকল্পনা**, এখনো নয়।

## ৬০ সেকেন্ডে ব্যবহার করে দেখুন
1. ফোনে https://rudra496.github.io/shasthosathi/ খুলুন → "Add to Home screen"।
2. 🩺 উপসর্গ যাচাই → *পেটে তীব্র ব্যথা* + *বারবার বমি* → **ফলাফল দেখুন** → "আজই হাসপাতালে" + কারণ দেখাবে + ফলোআপ তৈরি হবে।
3. 🤰 মা ও শিশু → তারিখ দিন → পুরো চেকআপ/টিকার সূচি + SMS টেক্সট।
4. এয়ারপ্লেন মোড চালু করুন → সব still চলবে (যাচাইকৃত)।
5. সুপারভাইজার ড্যাশবোর্ড → KPI, মডেল তুলনা, ২০২৬ আউটলুক, ম্যাপ, বুলেটিন।
